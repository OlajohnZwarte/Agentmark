# GitHub setup — 10 minutes, no git commands needed

## 1. Create the repo (2 min)
1. Go to https://github.com/new (sign in, or create a free account first).
2. Repository name: `agentmark`
3. Set it to **Public**.
4. Do NOT tick "Add a README" — click **Create repository**.

## 2. Upload the code (3 min)
1. On the new repo page, click **uploading an existing file**.
2. Muse will send you `agentmark-repo.zip` — unzip it on your phone/computer first,
   then drag in ALL the extracted files and folders (contracts, frontend, docs,
   scripts, test, README.md, LICENSE, etc.).
   - If dragging folders fails on mobile, use a computer, or upload in two batches.
3. Click **Commit changes**.

## 3. Turn on the website (2 min)
1. In the repo: **Settings → Pages**.
2. Under "Build and deployment", Source: **Deploy from a branch**.
3. Branch: **master** (or main), folder: **/docs** → Save.
4. After ~1 minute the page shows your site URL, like
   `https://YOUR-USERNAME.github.io/agentmark/` — that is the dApp website.
   Send that URL to Muse.

## 4. Tell Muse the repo link
Send the repo URL (e.g. `https://github.com/YOUR-USERNAME/agentmark`).
Muse will finish the submission pack with both links.
